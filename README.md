<h2 id="english">English Documentation</h2>

### 🧠 The Concept
"Boring Social Media" is an open-source Chrome Extension designed to break the dopamine loop created by social media algorithms. By stripping away colors (applying a strict grayscale filter) and presenting harsh scientific facts about social media addiction during the first 10 seconds of your visit, it makes endless scrolling significantly less appealing.

### ✨ Features
- **⚫ Grayscale Mode:** Automatically turns Instagram, X (Twitter), Facebook, TikTok, Threads, and Reddit completely black and white.
- **💡 Scientific Facts Toast:** Displays a minimalistic popup with a randomized scientific fact about social media side-effects (disappears after 10 seconds).
- **⏱️ 5-Minute Emergency Pause:** Need to see a colorful post for work? Hit the panic button in the extension popup to disable the filter for exactly 5 minutes.
- **🌐 Bilingual Support:** Choose between English and Persian for the scientific facts and UI.

### 🚀 Installation (Developer Mode)
1. Clone this repository or download it as a ZIP file.
```bash
   git clone [https://github.com/YOUR_GITHUB_USERNAME/boring-social-media.git](https://github.com/YOUR_GITHUB_USERNAME/boring-social-media.git)
   ```
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** (top right corner).
4. Click on **Load unpacked** and select the extension folder.
5. Pin the extension and enjoy the boredom!

### 🔒 Privacy Policy
We value your privacy. This extension works **100% locally and offline**. It does not track, collect, store, or transmit any personal data or browsing history. Permissions are strictly used for UI adjustments on targeted domains.
